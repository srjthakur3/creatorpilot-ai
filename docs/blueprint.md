# **App Name**: CreatorPilot AI

## Core Features:

- AI Content Generation: Leverages AI to generate video scripts, hooks, SEO titles, hashtags, and scene breakdowns based on user input and selected language.
- User Input & Configuration: Allows users to input a topic and select a language for content generation.
- Multi-Output Display: Presents all generated content outputs clearly: Viral Hook, 60 Second Script, Scene Breakdown, SEO Title, and Hashtags.
- User Authentication: Secure user login and signup functionality using Firebase Authentication.
- Plan Tiers: Provides UI elements to differentiate between Free and Pro plans, enabling tiered access to features.
- Dashboard Management: Centralized dashboard for all content generation and management tasks.
- Data Persistence: Saves user data and generated content, utilizing Firestore for database operations.

## Style Guidelines:

- Primary color: Energetic Orange (#F57C00) for creativity and calls to action.
- Background color: Deep Black (#121212) to create a professional, focused environment.
- Accent color: Soft Gray (#424242) for secondary elements and subtle contrasts.
- Font pairing: 'Space Grotesk' for headlines and 'Inter' for body text to combine a modern, techy feel with objective readability.
- Minimalist and professional icons that align with creator tools, emphasizing clarity and function.
- Responsive design ensuring a seamless experience across desktop, tablet, and mobile devices. Professional, uncluttered layout prioritizing content and functionality.
- Subtle fade-in animations for generated content and smooth transitions between pages.
